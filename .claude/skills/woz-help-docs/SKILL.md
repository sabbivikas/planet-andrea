# Woz Help Docs

Woz is a platform that builds full-stack, business-quality mobile apps from plain English descriptions. No coding required — Woz handles architecture, security, backend, database, and deployment.

## Key Facts

- **No coding needed.** Describe your app in plain English; Woz's AI handles the rest.
- **Builds iOS and Android.** Preview is iOS-only for now; apps launch to both stores.
- **Real auth and AI chat.** Apps include working email sign-up/login and customized AI chat out of the box.
- **Export code.** Paid users can download their app's source code from the "Your Projects" page.
- **Undo changes.** Click the notification icon on the App Preview page to access version history and restore previous versions.
- **Connect coding tools.** Paid users can SSH into Cursor, VS Code, or Claude Code from the App Preview page (click the code icon).
- **Share your app.** Click the Share button on App Preview to get a shareable link.
